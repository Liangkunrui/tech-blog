# 技术博客前端（Vue3）需求设计

- 版本：v0.1（初稿）
- 状态：规划中
- 对应后端：[需求文档](../../docs/需求文档.md)（API 以实际接口为准，见文末接口对照表）

---

## 1. 项目概述

### 1.1 定位

为 `tech-blog` 后端提供浏览器端界面，覆盖**浏览、创作、互动、通知**完整闭环。前后端分离部署：前端 `web/` 目录（Vue3 SPA），后端 `src/` 目录（SpringBoot API）。

### 1.2 技术选型

| 技术 | 版本 | 用途 |
| ---- | ---- | ---- |
| Vue 3 | 3.5.x | 框架（Composition API + `<script setup>`） |
| Vite | 5.x | 构建工具 + 开发代理（`/api` → 后端 8080，免 CORS） |
| TypeScript | 5.x | 类型安全 |
| Vue Router | 4.x | 路由 |
| Pinia | 2.x | 状态管理（登录态、Token） |
| Axios | 1.x | HTTP 客户端（拦截器统一带 Token、处理 401） |
| marked | 14.x | Markdown 渲染（文章内容） |

> 不引入重型 UI 组件库（如 Element Plus）：博客页面以简洁为主，手写样式，保持依赖最小化。

### 1.3 页面清单

| 路由 | 页面 | 说明 | 访问控制 |
| ---- | ---- | ---- | ---- |
| `/` | 首页 | 文章分页列表、热点 TopN、分类/标签筛选、关键词搜索 | 公开 |
| `/articles/:id` | 文章详情 | Markdown 渲染、作者/分类/标签、点赞/收藏/评论、浏览量 | 公开（互动需登录） |
| `/login` | 登录 | 用户名/密码登录，存储 Token | 公开 |
| `/register` | 注册 | 用户名/密码/昵称/邮箱 | 公开 |
| `/write` | 发布文章 | 标题/内容（Markdown）/分类/标签/摘要，支持编辑 | 需登录 |
| `/me` | 个人中心 | 我的文章/收藏/关注/粉丝、修改资料/密码 | 需登录 |
| `/notifications` | 通知中心 | 通知列表、未读计数、标记已读 | 需登录 |

### 1.4 全局设计

- **状态**：`userStore`（Pinia）保存 Token 与用户信息；`localStorage` 持久化 Token，刷新不丢登录态
- **请求层**：axios 实例 `baseURL = /api`（开发走 Vite 代理）；请求拦截器自动附加 `Authorization: Bearer <token>`；响应拦截器统一处理 `code !== 200`（弹提示、401 跳登录）
- **路由守卫**：`/write`、`/me`、`/notifications` 未登录时跳转 `/login`
- **布局**：`DefaultLayout` 顶栏（Logo、导航、登录状态区）+ 内容区 + 页脚

## 2. 页面需求详述

### 2.1 首页 `/`

- 顶部：热点 TopN 横向展示（标题、浏览量）
- 筛选区：分类下拉、标签列表、关键词输入、排序（最新/热度）
- 列表：分页展示文章卡片（标题、摘要、作者昵称、分类、浏览量/点赞/评论数、发布时间）
- 分页控件：上一页/下一页

### 2.2 文章详情 `/articles/:id`

- 标题、作者信息、分类/标签、发布时间、浏览量
- Markdown 内容渲染（marked；代码块样式预留）
- 互动区（登录后可用）：点赞（状态高亮 + 计数）、收藏、评论列表 + 发表评论
- 敏感词评论显示"待审核"状态

### 2.3 登录/注册

- 表单校验（必填、长度）；提交后跳转首页；错误信息展示后端 message

### 2.4 发布文章 `/write`

- 字段：标题、分类（选择）、标签（逗号分隔输入）、摘要、内容（Markdown）
- 预览切换（textarea ↔ marked 渲染）
- 编辑模式：路由带文章 ID（`/write?id=123`）加载已有文章

### 2.5 个人中心 `/me`

- Tab：我的文章 / 我的收藏 / 我的关注 / 我的粉丝 / 资料设置
- 资料设置：昵称、邮箱、简介；修改密码（旧+新）

### 2.6 通知中心 `/notifications`

- 未读数角标（顶栏）；通知列表（类型图标 + 内容 + 时间）；全部已读/单条已读

## 3. API 对接对照表（后端已实现）

| 功能 | 方法 | 路径 |
| ---- | ---- | ---- |
| 注册/登录 | POST | `/api/auth/register` `/api/auth/login` |
| 当前用户 | GET/PUT | `/api/users/me`、`/api/users/me/password` |
| 文章列表/详情 | GET | `/api/articles`、`/api/articles/{id}`、`/api/articles/hot` |
| 发布/编辑/删除 | POST/PUT/DELETE | `/api/articles`、`/api/articles/{id}` |
| 分类/标签 | GET | `/api/categories`、`/api/tags` |
| 评论 | GET/POST | `/api/articles/{id}/comments` |
| 点赞/收藏/关注 | POST/DELETE/GET | `/api/articles/{id}/like|favorite`、`/api/users/{id}/follow`（含 status） |
| 个人中心 | GET | `/api/users/me/articles|favorites|following|followers` |
| 通知 | GET/PUT | `/api/notifications`、`/unread-count`、`/{id}/read`、`/read-all` |

> 统一响应：`{code, message, data}`；`code=200` 成功，`401` 未登录，`403` 无权限，`404` 不存在。

## 4. 验收标准（总）

1. `npm run dev` 启动，`/api` 代理到后端 8080，全流程联调可用
2. 注册→登录→发文→浏览→互动→收通知闭环无报错
3. 401 自动跳登录；Token 持久化刷新不丢
4. Markdown 文章正常渲染
5. `npm run build` 构建通过
