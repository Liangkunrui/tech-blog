# 技术博客前端（Vue3）开发计划

- 版本：v0.1（初稿）
- 状态：规划中
- 前置条件：需求设计 v0.1 评审通过

---

## 1. 总体安排

| 阶段 | 内容 | 交付物 | 预计工时 |
| ---- | ---- | ---- | ---- |
| F0 | 工程搭建 | Vite+Vue3+TS 骨架、路由、Pinia、Axios 封装、布局、构建通过 | 0.5~1 天 |
| F1 | 认证与布局 | 登录/注册页、路由守卫、用户状态、顶栏导航 | 0.5~1 天 |
| F2 | 文章浏览 | 首页列表/筛选/分页、热点 TopN、详情页 + Markdown 渲染 | 1~2 天 |
| F3 | 创作与互动 | 发布/编辑文章、评论、点赞、收藏、关注 | 1~2 天 |
| F4 | 个人中心与通知 | 我的文章/收藏/关注/粉丝、资料/密码、通知中心 | 1 天 |
| F5 | 联调与完善 | 全流程联调、样式打磨、构建/部署说明 | 0.5~1 天 |

- M1（F0+F1）：工程可跑，登录闭环
- M2（F2+F3）：浏览与创作闭环
- M3（F4+F5）：个人中心 + 通知 + 全流程可用

---

## 2. 各阶段任务

### F0 工程搭建
- [ ] Vite 创建 Vue3 + TS 工程（`web/` 目录）
- [ ] 依赖：vue-router、pinia、axios、marked
- [ ] vite.config.ts：`/api` 代理到 `http://localhost:8080`
- [ ] Axios 封装：BaseURL、Token 拦截器、统一响应/401 处理
- [ ] Pinia userStore：Token 持久化（localStorage）
- [ ] 路由表 + 全局守卫；DefaultLayout（顶栏/内容/页脚）
- [ ] `npm run build` 通过

### F1 认证
- [ ] 登录页（表单校验、错误提示、登录后跳转）
- [ ] 注册页
- [ ] 顶栏登录状态区（昵称、退出登录）

### F2 文章浏览
- [ ] 首页：文章列表（分页、分类/标签/关键词、最新/热度排序）
- [ ] 热点 TopN 区块
- [ ] 详情页：信息区 + Markdown 渲染（marked）+ 浏览量

### F3 创作与互动
- [ ] 发布页：标题/分类/标签/摘要/内容 + 预览切换；编辑模式
- [ ] 点赞/收藏按钮（状态 + 计数联动）
- [ ] 评论列表 + 发表；敏感词评论显示待审核

### F4 个人中心与通知
- [ ] 我的文章/收藏/关注/粉丝 Tab
- [ ] 资料修改、修改密码
- [ ] 通知列表、未读角标、标记已读

### F5 联调与完善
- [ ] 注册→发文→浏览→互动→通知全流程联调
- [ ] 样式与响应式打磨
- [ ] README 补充前端启动说明；`npm run build` 产物说明

---

## 3. 风险与对策

| 风险 | 对策 |
| ---- | ---- |
| 后端 API 字段与前端假设不一致 | 以实际接口联调为准，集中维护 `api/` 模块 |
| 跨域 | 开发用 Vite 代理；生产由网关/反向代理同源 |
| Markdown 渲染 XSS | 渲染前转义 HTML（marked 安全选项），不引入执行 HTML 的库 |
| Token 过期 | 响应 401 统一清理登录态并跳登录 |
